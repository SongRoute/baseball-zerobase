# 시스템 아키텍처

> 학습 경로 / 서빙 경로, 데이터 흐름. (다이어그램은 추후 추가)

## 두 경로, 하나의 스펙
- 오프라인 학습 경로: Statcast → 클러스터링 → 학습데이터 재구성 → transition NN + Q함수.
- 라이브 서빙 경로: StatsAPI → 어댑터 → 상태벡터 → (사전계산 캐시 룩업) → Top-1/2/위험.
- 두 경로는 **공유 상태공간 스펙 + 공유 룩업 테이블**로 강제 통일 (DESIGN_DECISIONS D3).

## 추론 코어 (실시간/사후 공통)
상태 → transition NN(행동 필터) → Q함수(정렬) → 출력 분기.

## 환경
- Mac 로컬(CPU): 데이터·클러스터링·분석. uv, ~/projects/baseball-zerobase, 데이터 로컬 디스크.
- Colab 유료(GPU): NN·FQI 학습.
- 코드 GitHub(SongRoute), 데이터·가중치 로컬/T7 SSD.

## 사전계산 캐시
