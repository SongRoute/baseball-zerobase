# 용어집

> 프로젝트 전역 용어 단일 정의. 다른 문서는 여기를 참조.

- **상태공간(state space)**: 추론 입력. base-out·count·이닝·점수차구간·투수클러스터·타자클러스터+위협도+개인피처. (D4)
- **행동공간(action space)**: 6구종 × 13존 = 78. (D5)
- **13존**: 9존(스트라이크존 3×3) + 외곽 상하좌우 4. 타자 기준 상대좌표. (D5)
- **transition NN**: P(결과|상태,행동), 4-클래스(strike/ball/foul/in-play). 추론 시 행동 필터. (D8)
- **Q함수**: (상태,행동)→기대실점. (D8)
- **FQI**: Fitted Q-Iteration. 오프라인 함수근사 RL. (D7)
- **RE24 / Run Expectancy**: 주자·아웃 상태별 기대 득점. reward 기반. (D9)
- **xwOBA**: expected weighted on-base average. 인플레이 보상 + 위협도 지표.
- **위협도(threat)**: 타자가 얼마나 강한가. 연속값, 클러스터링 안 함. 승부 회피 판단용. (D11)
- **약점유형(weakness type)**: 타자를 어떻게 공략하나. 클러스터링 대상, 절대성적 제외. (D11)
- **정배/역배**: 모델 추천대로 갔는지(정배) / 다르게 갔는지(역배). 제품 핵심 프레이밍.
- **표본수 게이트**: (상태,행동) 관측이 임계값 미만이면 추천 제외. (D10)
- **분포 시프트**: 오프라인 RL에서 데이터에 없는 행동을 과대평가하는 문제. (D10)
