# 평가 방법론

> 추천은 본질적으로 "정답 검증 불가"(반사실). baseline도 이 한계 인정.
> 우리 평가는 세 층으로 구성.

## 1. 구성요소 손실 (간접)
- transition NN: Cross Entropy / Brier. baseline 목표 CE ≤ 0.861 재현.

## 2. 야구 상식 정성 해석
- 히트맵/추천이 야구 상식과 부합하는가(스트라이크 누적 시 보수적, 3-0 존 안 선호, 유인구 로직 등).
- baseline이 실제로 쓴 평가 방식.

## 3. 백테스팅 — 약한 정량 (우리 기여)
- baseline이 future work로 미룬 부분.
- 과거 데이터에서 모델 추천 vs 실제 결정 비교, 추천대로 한 경우의 결과 분포 관찰.
- "추천이 최적"이 아니라 "MLB 집단지성과 정합적"임을 보이는 수준 (DESIGN_DECISIONS D1).

## 주의
- 단일 사례로 추천의 옳고 그름을 판정하지 않는다(이상치). 집계 수준에서만 논한다.
