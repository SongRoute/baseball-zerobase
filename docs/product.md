# 제품 정의 상세

> PROJECT_PLAN의 제품 정의를 확장. 사용자·UX 철학.

## 목표 사용자
가볍게 야구를 즐기는 시청자. 야구 너드·전문가 아님.

## 핵심 경험
"지금 상황엔 몸쪽 높은 직구가 유리" → 시청자가 궁금해하며 시청 → 실제 투수 선택과 비교(정배/역배).
- 예측이 맞든 틀리든 둘 다 콘텐츠(맞으면 정배, 틀리면 "왜 반대로?").
- 추천 정확성을 주장하지 않음 → 평가의 "정답 없음" 한계를 제품으로 우회 (DESIGN_DECISIONS D1).

## 표현 원칙
- 내부 숫자(기대실점 등)는 시청자에게 직접 노출 안 함.
- 존 번호 → 자연어("몸쪽 높게"), 핸드니스 반영.
- 정배/역배 프레이밍으로 직관화.

## 기능 우선순위
Top-1 필수 → 2순위 → 위험 후보 → (후순위) LLM 자연어 해설.
