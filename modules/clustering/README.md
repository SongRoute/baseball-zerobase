# 모듈: clustering

> 역할: 투수/타자 클러스터링 + 위협도 산출
> 레이어: 1 · 의존: data
> 전역 결정·금지사항은 루트 `DESIGN_DECISIONS.md` 참조. 이 문서는 모듈 개요만 담는다.

## 입력
raw parquet

## 출력
클러스터 결과 + 위협도 + 선수ID→클러스터 룩업 테이블

## 문서
- `README.md` (이 문서): 개요·입출력·의존성.
- `SPEC.md`: 상세 명세. **작업 직전에 작성**(미리 추측으로 채우지 않음).
- `EXPERIMENTS.md`: 방법론 후보 비교·실험 기록.

## 상태
- [ ] SPEC 작성
- [ ] 구현
- [ ] 검수 (Song)
