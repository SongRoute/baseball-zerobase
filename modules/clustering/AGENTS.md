# AGENTS.md — clustering 모듈

루트 `AGENTS.md`와 `DESIGN_DECISIONS.md`를 먼저 따른다. 아래는 이 모듈 로컬 규칙.

## 이 모듈의 핵심 금지/주의 (가장 위반하기 쉬운 곳)
- 타자 약점유형 클러스터링에 **절대 생산성 지표(wOBA, HR, 타율 등) 금지** (DESIGN_DECISIONS 금지사항 1). 약점 축은 상대적 강약만.
- 위협도는 클러스터링에 넣지 말고 **별도 연속값(xwOBA)**으로 산출 (D11).
- **투수 클러스터로 타자 데이터를 쪼개지 말 것** (금지사항 2). 두 축 독립.
- 표준화 필수. 최소 타석/투구 수 필터. 노이즈(미할당) fallback 규칙 필요.
- 방법(UMAP/HDBSCAN, K 등)은 확정 아님 → 실험 후 선택. EXPERIMENTS.md에 비교 기록.

## 산출물
- 클러스터 결과 + 위협도 + 선수ID→클러스터 룩업 테이블
- 클러스터 프로파일 + 클러스터별 대표 선수 5명 (사람이 야구 지식으로 검수)
