# Baseball Zerobase

Baseball Zerobase는 누수 방지 MLB 선발투수 전략 연구 파이프라인을 위한
클린룸 재작성 프로젝트입니다. 이 저장소는 이전 프로젝트의 코드, 모델 가중치,
또는 처리된 데이터를 사용하면 안 됩니다.

## 범위

- 제품 범위는 MLB 선발투수 전용입니다. 불펜 추천은 범위에 포함되지 않습니다.
- Milestone 1-2는 누수 방지 데이터 기반과 경험적 베이스라인만 구축합니다.
- 아직 신경망 모델, 추천 엔진, API, 웹 UI는 없습니다.
- 개발 중에는 잠긴 테스트를 사용하면 안 됩니다.

## 현재 인터페이스

초기 명령줄 인터페이스는 버전 명령만 제공합니다.

```bash
uv run baseball-zerobase version
```

파이프라인 명령은 이후 마일스톤 작업에서 추가됩니다.
